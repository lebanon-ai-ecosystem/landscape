# Lebanon AI landscape

A neutral, open source map of the companies, research groups, and enablers building AI in Lebanon, plus Lebanese-founded AI companies operating abroad.

The site is generated by [landscape2](https://github.com/cncf/landscape2), the same tool that builds the CNCF landscape. This repository holds only our data, settings, guide content, and logos.

Working name and domain are placeholders until the project name is chosen.

## Repository layout

| Path | Purpose |
| --- | --- |
| `data.yml` | Every entry, organized by category and subcategory |
| `settings.yml` | Branding, colors, and the four map views (groups) |
| `guide.yml` | Content for the Guide page |
| `logos/` | One SVG per entry |
| `assets/` | Header and footer logos for the site itself |
| `.github/workflows/build.yml` | Validate on PRs; build and deploy to GitHub Pages on merge and nightly |
| `.github/ISSUE_TEMPLATE/add-entry.yml` | Structured form for new entries, corrections, and removals |

## Build locally

Install landscape2 (pinned in CI to v1.1.0):

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/cncf/landscape2/releases/download/v1.1.0/landscape2-installer.sh | sh
```

Validate, build, and preview:

```sh
landscape2 validate data --data-file data.yml
landscape2 validate settings --settings-file settings.yml
landscape2 validate guide --guide-file guide.yml

landscape2 build --data-file data.yml --settings-file settings.yml \
  --guide-file guide.yml --logos-path logos --output-dir build

landscape2 serve --landscape-dir build   # http://127.0.0.1:8000
```

## First-time setup checklist

- [ ] Replace `ORG` in `settings.yml` with the GitHub org name
- [ ] Replace `https://example.org` in `settings.yml` with the project domain
- [ ] Replace the placeholder header and footer logos in `assets/`
- [ ] Enable GitHub Pages with source set to GitHub Actions
- [ ] Add a `LANDSCAPE_GITHUB_TOKENS` secret (comma-separated tokens, `public_repo` scope) to collect GitHub stats
- [ ] Set the contact email in `CODE_OF_CONDUCT.md` and `CONTRIBUTING.md`
- [ ] Remove each `Placeholder:` entry once its subcategory has a real one
