# Lebanon AI Ecosystem

A neutral, open source landscape map of the companies, research groups, and enablers building AI in Lebanon, plus Lebanese-founded AI companies operating abroad.

The site is generated by [landscape2](https://github.com/cncf/landscape2), the same tool that builds the CNCF landscape. This repository holds only our data, settings, and guide content. Entries appear as names, not logos: `scripts/generate-name-logos.py` draws each name in one font at one shared size before every build.

Live site (until a custom domain is set): https://lebanon-ai-ecosystem.github.io/landscape

## Making changes

See [MAINTAINING.md](MAINTAINING.md) for how changes go live, which files to touch for each kind of change, and the review checklist. To propose an organization, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Repository layout

| Path | Purpose |
| --- | --- |
| `data.yml` | Every entry, organized by category and subcategory |
| `settings.yml` | Branding, site colors, and the four map views (groups) |
| `category-colors.json` | One header color per category |
| `scripts/apply-category-colors.py` | Post-build step that applies `category-colors.json` |
| `guide.yml` | Content for the Guide page |
| `logos/` | Generated name images (not committed) |
| `scripts/` | Name-image generator, category color patch, Inter font |
| `assets/` | Site header and footer logos, favicon, and social preview card |
| `brand/` | SVG sources for the cedar mark, wordmarks, and GitHub avatar |
| `.github/workflows/build.yml` | Validate on PRs; build and deploy to GitHub Pages on merge and nightly |
| `.github/ISSUE_TEMPLATE/add-entry.yml` | Structured form for new entries, corrections, and removals |

## 16:9 slide

Every deploy also publishes the whole map as one 1920x1080 slide for presentations: [PNG](https://lebanon-ai-ecosystem.github.io/landscape/downloads/lebanon-ai-ecosystem-slide.png), [PDF](https://lebanon-ai-ecosystem.github.io/landscape/downloads/lebanon-ai-ecosystem-slide.pdf). To make it locally after generating the name logos: `python3 -m pip install playwright && python3 -m playwright install chromium`, then `python3 scripts/make-slide.py data.yml logos category-colors.json downloads`.

## Build locally

Install landscape2 (pinned in CI to v1.1.0):

```sh
curl --proto '=https' --tlsv1.2 -LsSf https://github.com/cncf/landscape2/releases/download/v1.1.0/landscape2-installer.sh | sh
```

Validate, build, and preview:

```sh
landscape2 validate data --data-file data.yml
landscape2 validate settings --settings-file settings.yml
landscape2 validate guide --guide-file guide.yml

python3 -m pip install fonttools PyYAML   # once
python3 scripts/generate-name-logos.py

landscape2 build --data-file data.yml --settings-file settings.yml \
  --guide-file guide.yml --logos-path logos --output-dir build
python3 scripts/apply-category-colors.py build category-colors.json

landscape2 serve --landscape-dir build
```

`settings.yml` sets `base_path: /landscape` for GitHub Pages, and `landscape2 serve` always serves at the root, so the preview above shows a blank page. To preview locally, either build with a copy of `settings.yml` that omits `base_path`, or mirror the Pages layout:

```sh
mkdir -p /tmp/site && cp -r build /tmp/site/landscape
cd /tmp/site && python3 -m http.server 8100   # http://127.0.0.1:8100/landscape/
```

## Category colors

landscape2 alternates every category between two colors. `scripts/apply-category-colors.py` patches the built site so each category uses its color from `category-colors.json`, in every view. Adding or renaming a category means adding or renaming its key there. If a landscape2 upgrade changes the bundle, the script fails the build rather than shipping a half-patched site.

## First-time setup checklist

- [ ] If the org name differs from `lebanon-ai-ecosystem`, update it in `settings.yml` and this README
- [ ] When a custom domain is ready: set it in `settings.yml` (`url`), delete `base_path`, and add it under Settings, Pages
- [ ] Enable GitHub Pages with source set to GitHub Actions
- [ ] Add a `LANDSCAPE_GITHUB_TOKENS` secret (comma-separated tokens, `public_repo` scope) to collect GitHub stats
- [ ] Set the contact email in `CODE_OF_CONDUCT.md` and `CONTRIBUTING.md`
- [ ] Remove each `Placeholder:` entry once its subcategory has a real one
